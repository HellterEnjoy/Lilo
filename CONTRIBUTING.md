# Contributing to Lilo

Thank you for your interest in Lilo. Lilo is intentionally maintained as a single-author project: the official implementation is written and maintained by the project owner.

## Issues and suggestions

You are welcome to open [GitHub Issues](https://github.com/HellterEnjoy/Lilo/issues) for:

- bug reports;
- feature requests;
- UI and UX suggestions;
- technical suggestions and implementation ideas.

Please include enough context to explain the problem or proposal clearly. Example code or pseudocode may be included as a suggestion or reference.

## Code contributions

Pull requests containing code changes are not accepted, and external code contributions are not incorporated into the official Lilo codebase.

Example code submitted with an Issue remains a suggestion only. If the project owner chooses to pursue a proposed feature or fix, they may implement it independently instead of merging the submitted implementation.

Documentation-only pull requests are also not expected unless the project owner requests one directly. Opening an Issue is the preferred way to suggest a documentation change.
